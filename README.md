# Syngenta Agri-AI Marketing Orchestration Platform

A high-fidelity, multimodal AI platform designed for automated vernacular marketing, geospatial intelligence, and proactive crop protection.

## 🚀 Core Features
- **Vernacular GenAI**: Powered by Gemini 2.5 & Sarvam AI for local language engagement.
- **Geospatial Intelligence**: Carto-integrated market penetration mapping.
- **Visual Diagnostics**: Multimodal pest identification engine.
- **Proactive Automation**: Weather-triggered early warning systems.

## 🛠️ Technology Stack
- **Frontend**: React, Vite, Leaflet, Carto.
- **Backend**: FastAPI, Python.
- **Intelligence**: Google Gemini, Sarvam AI, XGBoost.
- **Data**: MongoDB Atlas (Vector Search enabled).
- **Deployment**: Google Cloud Run, GitHub Pages.
