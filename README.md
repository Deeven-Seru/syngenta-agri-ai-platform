# Syngenta Agri-AI Marketing Orchestration Platform

A high-fidelity, multimodal AI platform designed for automated vernacular marketing, geospatial intelligence, and proactive crop protection.

## 🌟 Project Vision
To bridge the gap between complex agricultural science and the local grower through **Semantic Intelligence**. By translating real-time field data into actionable, vernacular advice, we empower farmers to make surgical decisions that increase yield and sustainability.

## 🚀 Core Features
- **Multilingual Campaign Engine**: Generates WhatsApp-ready content in Marathi, Hindi, and Telugu using **Gemini 2.5 Flash**.
- **Geospatial Market Heatmaps**: Powered by **Carto & Leaflet** for district-level grower density and campaign ROI visualization.
- **Proactive Early Warning**: Automated campaign triggers based on **Meteoblue** weather anomalies (Humidity spikes/Soil moisture drops).
- **Vision AI Diagnostics**: Multimodal pest and disease identification for instant field support.

## 🛠️ Technical Architecture
- **Frontend**: React 19, Vite, Recharts, Leaflet.css.
- **Backend**: FastAPI (Python 3.11+), Pydantic v2.
- **Database**: MongoDB Atlas with **Vector Search** for semantic grower profiling.
- **Cloud**: Google Cloud Run (Autoscaling).
